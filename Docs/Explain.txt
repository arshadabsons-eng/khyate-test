Build a full **Admin Dashboard** for **Khyate**, an Arabic-English tailor marketplace. Use **React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts + TanStack Table**. Brand primary color is `#2D7A2D` (green) with white backgrounds. Use Tabler icons throughout. All monetary values display in AED.

---

## Design System

Primary green: `#2D7A2D` | Light green surface: `#E8F5E9` | Dark green: `#1B5E20` | White page background | Sidebar background in `#2D7A2D` with white text and icons | Status badges: green for active/success, amber for pending/warning, red for danger/blocked/failed, blue for info | All tables built with TanStack Table with sort, filter, pagination, row selection, and bulk action toolbar | All destructive actions behind a confirmation dialog | All loading states use skeleton loaders | All empty states show an icon with a helpful message | All forms show inline validation errors | Monetary values formatted as AED X,XXX.XX | Dates formatted as DD MMM YYYY

## Data Structure to Build

**Material** has: name, name_ar, material_type (enum: wool, cotton, silk, micromodal, polyester, linen, chiffon, velvet, denim, georgette, crepe, satin, other), quality_tier (enum: affordable, premium, luxury), color (name, hex code, is_available), properties (array of tags: breathable, stretchable, wrinkle-resistant, hypoallergenic, dry-clean-only, machine-washable, lightweight, heavyweight, sheer, opaque), price_per_meter_fils, stock_meters, minimum_order_meters, origin_country, care_instructions, images (up to 5), is_active

**Gender targeting** on every listing and tailor profile: enum (male, female, both). Female tailors or tailors accepting female customers are tagged. Customer filtering respects this. Female customers browsing see only tailors marked female or both.

**Dress categories** are hierarchical: root gender → category → subcategory. Examples: Female → Traditional Wear → Abaya, Jalabiya, Kaftan | Female → Formal → Evening Gown, Suit, Blazer | Female → Casual → Dress, Top, Skirt | Male → Traditional → Kandura, Thobe, Bisht | Male → Formal → Suit, Blazer, Trousers, Shirt | Male → Casual → T-Shirt, Jeans, Shorts | Unisex → Sportswear, Workwear

**Tailor plans**: Basic (free, 10 active listings, 15% commission, no featured), Professional (AED 99/month, 50 listings, 10% commission, 1 featured slot), Premium (AED 249/month, unlimited listings, 7% commission, 3 featured slots, priority dispute handling, verified badge, female-only filter eligibility)

**Customer measurements** stored per profile: bust/chest cm, waist cm, hips cm, shoulder width cm, sleeve length cm, inseam cm, outseam cm, neck cm, thigh cm, ankle cm, wrist cm, height cm, weight kg, fit preference (slim, regular, loose). Customers can have multiple named measurement profiles (e.g. Self, Mother, Daughter). Default profile auto-attaches to every custom stitch order.

**Sizes**: standard sizes (XS, S, M, L, XL, XXL, XXXL) plus custom (uses measurement profile). Tailors define which sizes they stock for readymade items.

## Animations Specification

All animations use Framer Motion with these exact behaviors: drawers slide in from right over 200ms with ease-out easing. Filter panel slides down with height animation over 150ms. Cards fade in on mount with staggered delay of 30ms per card. Color swatches expand on hover over 100ms. Property tags expand inline over 150ms. Page tab transitions fade out old content and fade in new over 150ms. Stock progress bars animate width on mount over 400ms ease-out. No spring animations. No rotation animations. No scale animations except 0.98 active press state on buttons. No parallax.
